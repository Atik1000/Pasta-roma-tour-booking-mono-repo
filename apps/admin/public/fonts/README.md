# GT Walsheim webfonts go here

Same three files as the public site — see `apps/web/public/fonts/README.md` for
the full explanation. The admin panel shares the theme, so it needs its own copy
of the licensed files:

    gt-walsheim-regular.woff2   →  weight 400
    gt-walsheim-medium.woff2    →  weight 500
    gt-walsheim-bold.woff2      →  weight 700

Without them the panel falls through to Outfit, exactly as the public site does.
